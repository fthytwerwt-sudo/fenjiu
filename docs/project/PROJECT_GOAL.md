# 项目目标｜PROJECT_GOAL

## 北极星目标

在尼泊尔为汾酒建立可核验、合规前置、可由双方协作执行的 TikTok 线上销售准备体系：先由供应链补齐可销售商品和本地履约条件，再由用户完成线上销售执行准备。研究、文档、同步包或 Git 状态均不等于商业上线。

## 当前阶段目标

**CONFIRMED**：进入供应链启动资料收集与首批 TikTok 商品上线准备。当前交付是可核验的资料清单、责任边界和首批 SKU 决策输入，不是 B2B 开发、多平台运营或完整 90 天运营系统。

## 当前成功定义

本阶段在以下事实有来源、日期、责任人和书面确认时成立：

1. 供应链提供真实 SKU、规格、价格与有效期、最低价、库存和补货信息；
2. 可售主体、品牌授权、产品合法可售和相关资质得到核验；
3. 账号主体与管理员权限、收款、仓储配送、退换货、质量、售后和结算责任明确；
4. TikTok 当前酒类内容、广告及转化边界得到当前书面核验；
5. 依据以上资料决定首批可上架 SKU，并在公开上线前进行一次合规和权限验收。

在任一条件缺失时，内部准备可继续，但公开传播、广告、真实销售、收款、订单和履约为 **BLOCKED**。
