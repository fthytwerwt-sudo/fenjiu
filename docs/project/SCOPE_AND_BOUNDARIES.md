# 范围与边界｜SCOPE_AND_BOUNDARIES

## 在范围内

- 汾酒尼泊尔市场研究、证据索引、渠道/供应链准备、合规前置与内部执行设计；
- 基于明确授权的资料整理、文档/表格生成、质量检查和项目交接；
- 在事实分级下维护项目状态、决策、风险、任务和同步包；
- 独立保存尼泊尔海鲜协作资料，并在需要时以独立任务与事实源处理。

## 不在范围内

- 把研究、计划、生成文档或 Git 提交宣称为已获许可、已合作、已上线、已履约或已销售；
- 未经用户和合规授权发送商务信息、触达线索、发布内容、投放广告、开设/操作平台账号、收款或下单；
- 用本仓库的尼泊尔海鲜资料推断汾酒产品、渠道、许可或客户事实，反之亦然；
- 把本地 `.env`、公开/私人联系方式、线索库、视频、渲染、缓存或 QA 截图上传到 Git 或默认同步包。

## 不可擅自修改

- 原始业务资料与已交付 DOCX/XLSX/PDF；如需更正，先新建可追溯版本，不覆盖原件。
- `research_*.json` 中的证据、标签或来源含义；变更前须有新的来源和明确记录。
- 事实源地图、当前状态和决定；除非本轮任务有相应证据。
- `.gitignore` 的安全规则；放宽前须先做秘密/隐私影响审计。

## 许可闸门

任何公开酒类信息、促销、广告、达人合作、直播、商品展示、导流、Shop、订单、付款或个人数据处理，必须先同时满足：合法性、平台政策、主体/授权、年龄与地域限制、隐私与数据归属、用户明确授权、可审计证据。任一缺失即 `BLOCKED`。
