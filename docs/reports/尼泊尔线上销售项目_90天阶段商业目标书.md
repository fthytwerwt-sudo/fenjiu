# 尼泊尔线上销售项目｜90天阶段商业目标书

> **副标题：** 以真实客户、成交、复购和可验证阶段成果作为验收标准
> **适用对象：** 合作方
> **版本：** 2026年8月30日

## 一句话项目目标

未来90天，将海鲜企业客户销售和汾酒20/30高端市场验证作为两条独立业务线推进。每30天分别拿出新的真实市场证据，90天后分别判断扩大、调整还是暂停。

本文件中的数字均为保守阶段目标和目标区间，不是收入、销量、订单或盈利保证。

## 当前重点

### 海鲜企业客户销售｜主验证线

未来90天主要看：

1. 哪些海鲜产品最容易产生真实采购。
2. 哪类企业客户最容易成交。
3. 是否出现复购。
4. 是否能持续形成订单。
5. 哪个线上客户来源真正有效。
6. 最后明确最值得继续投入的产品和客户方向。

### 汾酒20/30｜同步验证线

未来90天主要看：

1. 尼泊尔是否真的存在汾酒20/30购买需求。
2. 哪类客户最容易产生兴趣。
3. 客户能够接受什么价格区间。
4. 汾酒20还是30更适合当地。
5. 是否能够产生真实询价和付费客户。
6. 是否值得扩大。

海鲜和汾酒分别验收，一条线的市场结果不能用来推断另一条线。

## T0｜90天正式启动条件

### 海鲜 T0

1. 至少1个海鲜产品具备基础销售资料。
2. 供应链有明确负责人可以承接客户。
3. 能够真实报价。
4. 能够完成成交后的履约。
5. 基础销售条件已经准备好。

### 汾酒 T0

1. 至少1个实际汾酒20/30商品已经确定。
2. 商品、价格和库存能够确认。
3. 基础销售和授权条件具备。
4. 有明确客户承接负责人。
5. 具备开展受控市场验证的条件。

**共同原则：** 条件没准备好，先补条件，不提前消耗90天验证周期。

## 海鲜｜90天企业客户销售验证

海鲜是未来90天的主要商业验证线。重点不是做多少内容，而是证明“有企业愿意买、有人再次购买、订单能够持续产生”。

**有效企业采购客户**：有明确采购用途、产品兴趣或需求，并愿意继续沟通价格、样品或采购安排的企业客户；不是只看过内容、却没有下一步的人。

### 0–30天｜证明有真实采购需求

**阶段目标：**

1. 8–12个有效企业采购客户。
2. 3个以上明确询价、样品或采购需求。
3. 1–2个真实付费客户。
4. 至少形成1笔完整成交。
5. 初步找出2–3个客户更感兴趣的产品。

**合作方能看到：** 有效企业客户数量、真实询价或采购需求数量、实际成交数量，以及被问得最多的产品。

### 31–60天｜证明可以重复成交

**阶段目标：**

1. 累计3–5个真实付费客户。
2. 至少1个客户再次购买。
3. 明确2个更容易成交的主推商品。
4. 明确1–2类更容易成交的企业客户。
5. 已成交客户有明确交付结果。

**合作方能看到：** 累计成交客户数、是否出现复购、哪些商品和客户类型更容易成交，以及客户最主要的真实反馈。

### 61–90天｜证明值得继续扩大

**阶段目标：**

1. 累计5–8个真实付费客户。
2. 至少2个稳定复购客户。
3. 出现连续真实订单。
4. 明确2–3个核心主推商品。
5. 找到至少1条可以重复获得企业客户的有效渠道。
6. 最终说清：什么商品、什么客户、什么客户来源最值得继续扩大。

**合作方能看到：** 成交趋势、复购情况、稳定客户数量、主推商品、最有效客户来源，以及下一阶段应该扩大什么。

### 海鲜90天结束时必须回答5个问题

1. 哪几个产品最好卖？
2. 哪类企业客户最好成交？
3. 有没有真实复购？
4. 客户主要从哪里来？
5. 是否值得扩大客户和商品供应？

## 汾酒20/30｜90天高端市场验证

汾酒不是本轮主要商业成果承担线，而是通过低成本、小范围验证，判断尼泊尔高端消费市场是否存在真实购买空间。只有出现明确购买证据后，才扩大投入。

### 0–30天｜验证真实兴趣和价格接受度

**阶段目标：**

1. 获得8–12个真实目标客户的有效市场反馈。
2. 明确客户对汾酒20/30的认知和兴趣。
3. 了解客户对价格的接受情况。
4. 找出1–2类最可能购买的人群。
5. 判断20和30哪个更容易被接受。
6. 条件允许时争取出现真实询价或明确购买意向。

**合作方能看到：** 真实客户反馈数量、最感兴趣的客户类型、价格主要反馈，以及汾酒20和30哪个接受度更高。

### 31–60天｜验证有没有真实付费需求

**阶段目标：**

1. 集中验证前30天最有兴趣的人群。
2. 获得真实询价、预订或实际购买证据。
3. 明确最容易被接受的产品。
4. 明确主要消费场景：商务、宴请、礼赠或自饮。
5. 找出客户不购买的主要原因。
6. 如果仍没有真实付费信号，保持低投入，不扩大。

**合作方能看到：** 真实询价数量、是否出现付费客户、最有购买可能的客户类型、接受度更高的消费场景，以及客户最主要的顾虑。

### 61–90天｜决定是否值得扩大

如果前两个阶段出现真实付费客户，继续观察：

1. 是否出现第二次购买。
2. 是否出现持续询价。
3. 是否出现客户转介绍。
4. 汾酒20/30哪个更适合主推。
5. 是否存在可以重复触达的高端客户来源。

最终必须给出“继续扩大、保持小范围验证、暂停”三者之一。

**合作方能看到：** 是否真的有人付费、是否有人再次购买或转介绍、20/30哪个更适合市场、哪类客户最值得继续开发，以及汾酒到底值不值得扩大。

### 汾酒90天结束时必须回答5个问题

1. 尼泊尔是否真的有人愿意买汾酒20/30？
2. 哪类人最容易接受？
3. 客户能够接受什么价格区间？
4. 汾酒20还是30更适合主推？
5. 是否值得扩大投入？

## 每30天，两条业务分别新增什么商业证据

| 时间 | 海鲜合作方看到的结果 | 汾酒合作方看到的结果 |
|---|---|---|
| 30天 | 企业客户、真实询价、首单、最受关注商品 | 客户反馈、价格接受度、目标人群、20/30偏好 |
| 60天 | 累计成交、首个复购、主推商品、重点客户类型 | 真实询价或付费信号、主要消费场景、客户顾虑 |
| 90天 | 稳定复购、持续订单、有效客户来源、核心主推商品 | 真实付费、复购或转介绍、主推产品、扩大或暂停结论 |

## 90天结束的最终判断

### 海鲜

| 结果 | 判断标准 |
|---|---|
| A. 继续扩大 | 已经形成真实成交、复购、稳定客户来源和明确主推商品。 |
| B. 调整后继续 | 市场存在真实需求，但商品、客户类型或客户来源需要继续优化。 |
| C. 停止或暂停 | 90天仍没有形成足够的真实成交和复购证据。 |

### 汾酒

| 结果 | 判断标准 |
|---|---|
| A. 继续扩大 | 已经出现真实付费，目标人群、价格接受度、产品偏好和重复需求比较明确。 |
| B. 保持小范围 | 市场有兴趣，但真实购买证据还不足，继续低成本观察。 |
| C. 暂停 | 真实购买意愿不足，或者外部销售条件长期无法满足。 |

**独立验收原则：** 海鲜和汾酒两条业务线独立验收。一条线表现不好，不自动否定另一条线；90天结束后，根据各自真实商业证据分别决定下一阶段投入。
