## 对汾酒的重写原则

1. 项目身份固定为汾酒尼泊尔，当前主线固定为 TikTok 线上销售准备。
2. 机制包只保存长期判断和协作方式，不保存实时商品价格、库存、账号、收款或履约资料。
3. 供应链责任边界必须和实际资料交付分开。
4. 海鲜作为独立业务线隔离。
5. GitHub `main` 是当前事实源；GPT Project 是机制层。
6. Codex 只做本地执行落库和 Git 收口，不替代用户外部授权。
7. 用户未手动上传 ChatGPT UI 前，不得声称 GPT Project 已学习或已生效。
