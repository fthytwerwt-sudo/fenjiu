# Codex / Work 任务交接模板

```markdown
# [任务名称]

## Goal｜目标

## Context｜上下文
- 项目业务线：汾酒 / 海鲜 / 协作机制 / 工具（只能选已确认范围）
- 当前阶段与事实源：

## Constraints｜边界
- 可修改文件：
- 禁止修改/禁止外发：
- 隐私、合规与 Git 约束：

## Impact check｜影响面检查
- 是否影响当前状态、决定、风险、下一步、同步包或生成物：
- 是否可能混入另一条业务线、秘密、联系方式、大文件或派生产物：

## Execution steps｜执行步骤
1.

## Done when｜完成标准
- [ ]

## Blocked if｜阻断条件
- [ ]

## Output｜回报格式
- 已确认事实 / 推断 / 未知 / 阻断
- 修改文件与验证证据
- Git 分支、commit、推送状态
- 下一步和需要用户确认项
```

交接方应先填写空项。执行方不得用推测补全空项。
