# 外部资料保真与执行桥接

## 外部资料范围

外部资料包括平台规则、供应链文件、合作方消息、截图、网页、研究报告、参考仓库、第三方建议和用户临时上传材料。

## 四步桥接

1. `保真提取`：只提取原文支持的事实、字段和限制。
2. `分级标注`：区分 `已确认`、`待验证`、`推测`、`BLOCKED`。
3. `冲突裁决`：和 GitHub 当前事实、用户本轮输入、合规闸门比较。
4. `执行转译`：把可执行内容转成问题清单、Codex 任务单或供应链资料请求。

## 禁止

- 不把外部资料摘要直接写成项目事实。
- 不把参考仓库业务内容迁移到汾酒。
- 不把平台历史规则当当前规则。
- 不把供应链口头范围写成已交付资料。
- 不把截图或聊天摘要当唯一事实源。

## 可写入 GitHub 的条件

外部资料要进入 GitHub 项目事实，必须有来源、日期、责任人或可回读证据，并说明事实等级。如果只是研究线索，写成 `待验证` 或放入问题清单，不升级业务状态。
