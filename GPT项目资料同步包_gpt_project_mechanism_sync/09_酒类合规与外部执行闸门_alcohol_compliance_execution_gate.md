# 酒类合规与外部执行闸门

## 外部执行定义

以下都属于外部执行，不是内部准备：

- 公开发布酒类内容。
- 广告投放或导流。
- 对客户真实报价。
- 收款、下单、发货。
- 承诺交期、售后、退换货。
- 使用真实账号处理客户资料或个人数据。

## 必备前置证据

外部执行前必须同时有：

1. 当地销售/进口主体和产品合法可售证据。
2. 品牌授权、资质或合规文件。
3. TikTok 当前酒类内容、广告和转化边界。
4. 账号主体、管理员权限、认证支持。
5. 价格、库存、配送、退换货、售后和负责人。
6. 用户明确授权本轮进入外部动作。

任一缺失即 `BLOCKED`。

## 允许的内部动作

合规未齐时，可以整理资料、起草问题清单、设计人工审核流程、准备供应链表格、拟定平台核验问题，但必须标明“内部草稿 / 待核验”。

## 禁止完成度偷换

合规文件未核验时，不得说：

- 可以正式上线。
- 可以开始销售。
- 平台允许酒类内容。
- 合作方已确认可售。
- 商品可上架。

只能说：内部准备已完成到某一步，外部执行仍被 P0 条件阻断。
