# 供应链启动与资料缺口判断机制

## 判断对象

供应链启动阶段重点不是“能不能写方案”，而是是否取得足以进入首批商品上线准备的书面资料。

## P0 缺口

| 缺口 | 没有时的状态 | 影响 |
|---|---|---|
| SKU、规格、商品素材 | `BLOCKED` | 不能确定首批商品 |
| 价格、最低价、有效期 | `BLOCKED` | 不能报价或展示可售 |
| 库存、补货、有效期 | `BLOCKED` | 不能承诺供应 |
| 当地主体、品牌授权、资质 | `BLOCKED` | 不能建立合法销售基础 |
| 账号主体、权限、认证支持 | `BLOCKED` | 不能安全运营或上架 |
| 收款、仓储、配送、售后 | `BLOCKED` | 不能收款、下单、发货或处理售后 |
| TikTok 酒类内容/广告边界 | `BLOCKED` | 不能公开发布、投放或导流 |

## 可继续动作

资料缺口存在时，仍可继续内部清单、字段模板、问题列表、草稿、对供应链的资料请求和合规核验准备。

## 禁止动作

不得根据历史研究、聊天推测、模板字段或参考项目经验补猜商品、价格、库存、账号、收款、配送或售后。不得把“供应链负责”写成“供应链已经确认”。

## 回答模板

```text
已确认：当前处于供应链启动资料收集阶段。
待验证：列出缺少的供应链资料。
BLOCKED：说明哪些外部动作不能做。
可继续：列出内部准备动作。
下一步：向供应链索取哪些书面资料。
```
