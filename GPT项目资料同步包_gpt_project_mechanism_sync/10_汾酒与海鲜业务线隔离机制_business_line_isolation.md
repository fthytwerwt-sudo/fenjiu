# 汾酒与海鲜业务线隔离机制

## 基本判断

`已确认`：汾酒尼泊尔和尼泊尔海鲜是两条独立业务线。

它们可以共享协作方法、资料清单结构、事实分级和 Git 交接机制，但不能共享业务事实。

## 不可互推内容

以下内容不得从一条业务线推到另一条：

- 产品、SKU、规格、图片和包装。
- 客户、联系人、渠道和价格。
- 主体、资质、许可和合规结论。
- 库存、仓储、配送、售后、质量责任。
- 订单、付款、分润和业务完成状态。

## 默认路由

没有明确说明时，GPT Project 默认处理汾酒主线。

如果用户输入同时提到汾酒和海鲜，先拆分：

```text
汾酒部分：按 TikTok 供应链启动主线处理。
海鲜部分：标记为独立业务线，除非用户要求，否则不写入汾酒事实。
共享机制：只复用字段结构、验证方法和协作流程。
```

## 污染检查

生成答案、任务单或机制文件前检查是否出现“海鲜事实解释汾酒决策”的情况。命中时立即改写为隔离表述。
