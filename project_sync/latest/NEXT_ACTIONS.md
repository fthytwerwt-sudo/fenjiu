# 下一步行动｜NEXT_ACTIONS

## 当前优先级

1. **合规与主体核验（A）**：建立一份由当地法律、主管机关、平台和销售/进口主体签字或书面回执支持的许可矩阵。
2. **产品与履约主数据（A）**：由供应链方提供 SKU、批次、规格、价格、库存、税费、配送、退货、质量与召回责任，并注明日期与负责人。
3. **账号与数据归属（A）**：确认账号主体、管理员、权限、客户数据、内容资产、CRM、收款和合作终止后的处理方式。
4. **最小试点裁决（B）**：只有 A 项完成后，按已确认渠道、合规边界和人审闸门设计单一最小试点；默认 `draft_only`，不自动外发。
5. **资料线范围（B）**：由用户确认海鲜协作资料是否仅作独立项目，还是需要建立有证据边界的共享供应链模块。

## 每项的完成证据

- 在 `CURRENT_STATUS.md`、`OPEN_QUESTIONS.md` 和 `RISKS_AND_BLOCKERS.md` 中同步更新；
