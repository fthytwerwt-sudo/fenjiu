# 风险与阻断｜RISKS_AND_BLOCKERS

| 编号 | 状态 | 风险/阻断 | 当前影响 | 安全处理 |
|---|---|---|---|---|
| R-01 | `BLOCKED` | 酒类公开传播、广告和平台能力未获得当前书面确认 | 不得发布、投放、达人合作、直播、导流或 Shop 执行 | 保持研究/内部草稿；由当地法律与平台书面核验 |
| R-02 | `BLOCKED` | SKU、价格、库存、主体、牌照和履约资料缺失 | 不得报价、下单、收款或承诺交期 | 取得产品与供应链主数据，明确责任人 |
| R-03 | `UNKNOWN` | 账号、数据、内容与收入归属未定 | 可能造成权限、数据和合作纠纷 | 在任何账号/CRM/内容生产前签署归属与退出规则 |
| R-04 | `INFERRED` | 不同日期的研究与平台信息可能已经过时 | 可能将历史公开资料误作当前许可 | 任何上线日重新核验权威来源与实际后台状态 |
| R-05 | `CONFIRMED` | 工作区包含大体积视频、图片、渲染、QA 和缓存 | Git/同步包可能膨胀并混入无关材料 | `.gitignore` 与同步包 allowlist 排除，按需在本地查阅 |
| R-06 | `CONFIRMED` | 本地存在 API Key 配置入口及线索联系字段 | 可能泄露凭据或不必要个人/业务信息 | `.env`、凭据提示文件与线索库不提交、不打包，并在构建时扫描 |

任何 R-01 至 R-03 未被书面解除时，Agent 的完成态只能是资料/机制完成，不得升级为商业、合规或销售完成。
