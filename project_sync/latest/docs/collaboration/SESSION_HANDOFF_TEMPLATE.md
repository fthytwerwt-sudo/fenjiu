# 新会话交接模板

将下列内容与最新 project_sync/latest 或其 ZIP 一并提供给新 ChatGPT、Codex 或 Work 会话。

    请先阅读同步包中的 AGENTS.md、PROJECT_ENTRY.md、BUSINESS_STATUS.md、
    CURRENT_STATUS.md、SOURCE_OF_TRUTH.md、SCOPE_AND_BOUNDARIES.md 和
    COLLABORATION_STATUS.md。

开始执行前，简短复述：

1. 汾酒当前真正做什么、主渠道和业务阶段；
2. 用户与供应链各自负责什么，以及哪些资料尚未实际提供；
3. 本轮已确认、推断、未知与阻断；
4. 当前任务边界、海鲜资料线边界，以及不能擅自做的事；
5. 会读取哪些原始事实源，何种证据满足完成，何种情况必须阻断；
6. 如任务影响 Git 或同步包，需要更新哪些业务/协作文件。

不要把研究、模板、同步包、文件生成、Git 提交或测试通过写成当地许可、合作确认、上线、销售或履约完成。不要混用汾酒和海鲜资料线。未经明确授权，不外发、不发布、不投放、不下单。
